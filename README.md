# RMVC 小车底盘示例嵌入式代码

## 使用物资

-   STM32f103c8t6 最小系统板
-   PS2 遥控手柄
-   L298N 电机驱动模块
-   LM2596 降压模块
-   GBJ37-520 电机

以上物资选择，不是唯一指定，例如PS2手柄可换为蓝牙模块等等。强烈建议自己去选型更好、更廉价的配件！

## 开发环境

-   Keil 5.36，ac5编译器
-   CubeMX
-   C 语言

## 实现功能

-   使用 L298N 驱动 GBJ37-520 直流电机
-   移植了 PS2 遥控手柄淘宝商家提供的现成代码，实现遥控器接受
-   简单的麦克纳姆轮底盘解算

## 电气连线

具体各个模块连线方式，请自行向你购买的淘宝商家要，或者在网上搜索教程

```mermaid
graph LR
12v锂电池 --12v--> LM2596降压模块
LM2596降压模块 --5v--> PS2遥控手柄
LM2596降压模块 --5v--> STM32f103c8t6最小系统板
12v锂电池 --12v--> L298N电机驱动模块 ----> GBJ37-520电机
```

## 目录说明

文件夹下分为三个模块：

```
├── App/            # 业务代码
│   ├── main.c      # 主程序
│   ├── motor.c     # 底盘控制
│   ├── ps2.c       # PS2 数据接受程序
│   ├── pwm.c       # PWM
│   ├── delay.c     # 软件延时函数
│   └── sys.c       # 系统配置相关
├── Bsp/                # 定义一些外设的设备的使用，给App里的程序提供便用的代码
├── Core/               # CubeMX自动生成配置，和main.c里自己写的一部分代码
├── Drivers/            # CubeMX自动生成的HAL库驱动    
├── MDK-ARM/            # Keil 5 工程文件
├── mxproject和rmvc.ioc # CubeMX配置文件
└── README.md           # 项目说明文件
```
